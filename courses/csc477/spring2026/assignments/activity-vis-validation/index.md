Work on this activity in groups of 2–4, working with people sitting around you. At the end of the activity, only one person needs to make a submission, but please include all participants' names. (Feel free to make your own placeholder submission to get rid of the to-do item in Canvas if you'd like).

I recommend working in a shared Google Doc (so everyone can contribute) or similar until you're ready to paste into Canvas. Please use markup and formatting to make the structure of your response clear, e.g., headings for each task, specific questions you're answering.

**Grading note**

This is an in-class participation activity, so on-task responses will be graded for completion rather than "correctness".
